## What Barbell Loader Does

Barbell Loader provides a focused way to decide how weight plates should be placed on a barbell. Instead of working through the loading process mentally, users can view the planned setup while organizing a training session.

The tool is particularly useful for percentage-based programs as well as ordinary lifting workouts. It combines plate planning and barbell loading guidance in a single browser interface, making it easier to confirm the intended weight before training begins.

## How to Use

1. Load Barbell Loader in a web browser.
2. Provide the workout percentage details by entering or selecting the required values.
3. Inspect the loading plan produced by the app.
4. Follow the visual layout to determine the plates needed on the bar.
5. Set up the barbell according to the displayed result.

When planning a normal training session, verify every target weight before lifting. If the workout percentage changes, adjust the inputs and review the updated arrangement.
